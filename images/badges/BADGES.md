# Accreditation & licensure badge library (behavioral-health builds)

A reference set of the standard licensure/accreditation marks a SUD/behavioral-health facility
may display, with the official source and verification method for each.

> **Usage rule (important):** every mark below is a **trademark** of its issuing body and may be
> displayed **only by a facility that currently holds that specific credential**, following the
> issuer's brand/usage rules. Prefer the issuer's **official verification widget/link** over a
> static copy so the badge is provably tied to the real, current credential. Confirm each client
> actually holds a credential before putting its badge on their site. The image files here are for
> layout/reference during a build — swap in the client's own official seal before launch.

| Mark | What it certifies | Official source / how to display | Verify link |
|---|---|---|---|
| **DHCS** (`dhcs-logo.png`) | California **Department of Health Care Services** — the state license to operate a SUD facility (the license #, e.g. NB's `330232AP`). | State agency logo; pair it with the facility's DHCS license number + expiration. | https://www.dhcs.ca.gov/ · license lookup via DHCS SUD provider directory |
| **LegitScript** (`legitscript-seal-example.png` = *example only*) | Addiction-treatment certification required to run ads on Google/Meta/Bing. **Per-entity** — each facility has its own seal ID. | **Use the official seal widget, not a static image:** `https://static.legitscript.com/seals/<YOUR-SEAL-ID>.js` (or `.png`). The example file is another facility's seal — never reuse it. | https://www.legitscript.com/websites/?checker_keywords=<domain> |
| **The Joint Commission — Gold Seal of Approval** (`joint-commission-gold-seal.gif`) | Independent accreditation of the facility's quality/safety. | Display the Gold Seal only if accredited; TJC provides the seal + brand rules to accredited orgs (often via a Yoshki verification widget). | https://www.qualitycheck.org/ (Quality Check lookup) · https://www.jointcommission.org/ |
| **CARF** *(no image — request from issuer)* | Commission on Accreditation of Rehabilitation Facilities — an alternative accreditation many SUD/residential programs hold instead of/alongside TJC. | CARF supplies the seal + usage guide to accredited orgs. | https://www.carf.org/ (provider search) |
| **NAATP** *(no image — membership mark)* | National Association of Addiction Treatment Providers — a **membership**, not an accreditation; a credibility signal. | Members may display the NAATP member mark per NAATP rules. | https://www.naatp.org/ (member directory) |
| **SAMHSA** *(reference only)* | Federal Substance Abuse & Mental Health Services Administration — a resource/authority, **not** a facility certification; don't imply endorsement. | Link out for resources (988, treatment locator); do not display as a credential. | https://www.samhsa.gov/ · https://findtreatment.gov/ |
